# D1: Vorher/Nachher – wichtig

Die fertige App enthält bereits die aufgeteilten Funktionen. Eine **Git-Commit-Historie wird nicht mitgeliefert**.
Für einen echten D1I-Nachweis solltest du selbst eine funktionierende imperative Erstversion entwickeln und committen, dann refactoren und erneut committen. Halte Testausgaben und Commit-IDs fest.
Für D1A sind in `services/performance_service.py` beide Algorithmen enthalten. Committe die Listenvariante zunächst als verwendete Implementierung; tausche sie danach gegen die Set-Variante, committe erneut und messe reproduzierbar mit `portfolio/benchmarks/benchmark_d1a.py`.
Nutze keine erfundenen Commits oder Messergebnisse.
